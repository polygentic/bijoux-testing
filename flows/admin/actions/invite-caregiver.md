# Admin Action: Generate Caregiver Invite

## UAT ID
UAT-L3.10

## Admin Action (execute in Chrome)
1. Navigate to http://localhost:3001/caregivers
2. Find any caregiver and click to open detail
3. Locate the "Generate Invite" button
4. Click it
5. Verify a success banner appears with an invite URL
6. Verify the URL follows a valid format
7. Take a screenshot

## Pass Criteria
- Generate Invite button visible on caregiver detail
- Clicking generates an invite URL
- Success banner displays the URL
- URL follows valid format
