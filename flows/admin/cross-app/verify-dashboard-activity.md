# Cross-App Verify: Dashboard Recent Activity

## UAT ID
UAT-L2.2

## Prerequisites
- Admin portal running at http://localhost:3001
- Logged in as admin@bijoux.app / Test1234!

## Steps
1. Navigate to http://localhost:3001 (dashboard)
2. Scroll to the Recent Activity section
3. Verify activity entries are present
4. Look for entries related to: booking creation, session completion, or caregiver actions
5. Verify entries have timestamps, actor info, and action descriptions
6. Take a screenshot

## Pass Criteria
- Recent activity section is visible and populated
- At least one entry relates to E2E flow activity
- Entries show timestamp, actor, and description
